Printing

About

Sends files to the printer connected to the server (through CUPS). PDF, images (PNG, JPEG, WebP, GIF, BMP, TIFF) and text files are printed directly; Word, Excel, PowerPoint and OpenDocument files too when LibreOffice is installed on the server. Everything is converted to PDF on the server first, 50 MB at most per file. Files can also be taken from cloud storage.
