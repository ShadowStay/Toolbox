Printing

About

Sends files to the printer connected to the server (through CUPS). PDF, images (PNG, JPEG, WebP, GIF, BMP, TIFF) and text files are printed directly; Word, Excel, PowerPoint and OpenDocument files too when LibreOffice is installed on the server. Files are converted to PDF on the server (50 MB at most each) and laid out on sheets as the preview shows: by default a document page fills one whole sheet and a picture is never enlarged. Files can also be taken from cloud storage.
