Iprix's Spells

Web tools for text, images and files. Text, image and file processing runs in the browser by default and can run on the server instead (Options).

Sign in

Tools

Features

Text

Find and replace with plain text or regular expressions, case conversion (upper, lower, title, sentence, camel, Pascal, snake, kebab, constant), line sort, deduplication, join and split, HTML tag stripping, extraction of emails, URLs and numbers, Base64, URL and HTML encoding, line and word diff.

Images

Layered editor: move, resize, rotate, crop and flip layers, per-layer filters, arrangement in a grid, tile split. Reads PNG, JPEG, WebP, GIF and BMP (TIFF and HEIC on the server) and writes PNG, JPEG, WebP and AVIF.

Files

Viewer for PDF, DOCX, spreadsheets, images, text and code, audio and video. Exports PDF pages as PNG or JPEG, DOCX as HTML, text or PDF, spreadsheets as XLSX, ODS, CSV, TSV, JSON or HTML. Merges several files into one PDF, text file or workbook.

Calculator

Expressions, unit conversion, equations with one unknown and linear systems, evaluated in the browser.

Storage and room

Shared file storage (500 GB) with resumable chunked uploads and zip download of folders. A room with text chat, WebRTC voice (up to 8 participants), screen sharing and a drawing board.

Tabletop

Character and enemy sheets stored per campaign, a server-side dice log, a battle map with tokens, walls, doors, fog of war and distance measuring, and a combat tracker with initiative and effect durations.

Processing

By default text, images and files are processed in the browser and never leave the device. With server processing selected in the Options dialog the same operations run on the server, which additionally reads TIFF and HEIC images and handles larger files. Both settings are stored in cookies. Cloud storage, the chat room and the tabletop always use the server.

Details

Are files uploaded?

Not in browser mode. In server mode a file is sent to the server for the task and deleted when it is closed or after 30 minutes without use.

Input formats of the file viewer

Images (PNG, JPEG, WebP, GIF, SVG, AVIF, BMP, ICO, plus TIFF and HEIC in server mode), PDF, Word (.docx), spreadsheets (XLSX, XLSM, XLS, ODS, CSV, TSV), text and code files, audio and video.

Requirements

A current web browser. Microphone and screen sharing in the chat room need HTTPS or localhost.

Access

This page is public. The tools are protected by a password.
