What you can do here

Work with text

Find and replace across a whole document, with optional regular expressions. Change case (UPPER, Title, camelCase, snake_case and more), sort and deduplicate lines, strip HTML, pull out email addresses and URLs, encode Base64 and URLs, and see exactly what changed between two versions of a text.

Edit and convert images

Every image is a layer you can drag, resize, rotate and crop. Apply filters, line several images up into a collage, cut one into tiles, and save as PNG, JPEG, WebP or AVIF.

View and convert files

Open PDFs, Word documents, spreadsheets, images, text, audio and video in one viewer. Export a PDF page as an image, a document as plain text or HTML, a spreadsheet as CSV or Excel, and combine several files into one PDF, text file or workbook.

Talk in the shared room

One chat room for everyone who is signed in, with a voice channel and screen sharing between browsers.

Your choice: browser or server

By default the tools run in your own browser, so your text and files stay on your device. If you prefer, switch to server processing in the Options dialog: the same tools then run on the site's server, which handles more formats (such as TIFF and HEIC photos) and large files, and keeps nothing once you are done. Animations are off by default and can be turned on in the same dialog. Both choices are remembered in a small cookie on your device.

Questions

Are my files uploaded?

Not in browser mode: files are opened and converted on your device. In server mode they are sent to the site's server for the task and deleted when you close the file or after 30 minutes.

Which file types can I open?

Images (PNG, JPEG, WebP, GIF, SVG, AVIF, BMP, ICO, plus TIFF and HEIC in server mode), PDF, Word (.docx), spreadsheets (XLSX, XLS, ODS, CSV), text and code files, MP3 and WAV audio, and MP4 and WebM video.

Do I need to install anything?

No. Everything works in a modern web browser. Microphone and screen sharing in the chat need a secure (https) connection.

How do I get in?

The tools are protected by a password. Use the sign-in link, enter the password, and the tools appear in the sidebar.
