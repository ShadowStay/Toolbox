# Project instructions

## Goal
Complete assigned software engineering tasks end to end.

## Workflow
1. Inspect the repository and understand its architecture before editing.
2. Identify the relevant files, dependencies, and existing tests.
3. Create a short implementation plan for non-trivial tasks.
4. Implement the requested change across all necessary files.
5. Run relevant tests, linters, and type checks.
6. Diagnose failures caused by your changes and fix them.
7. Re-run the relevant checks after fixing failures.
8. Review the final diff for regressions, security issues, and unrelated changes.
9. Summarize what changed, what was tested, and anything still incomplete.

## Constraints
- Work only within this repository.
- Never use cloud AI services or external model APIs.
- Do not fetch external resources or install packages without approval.
- Never expose, print, or commit secrets, API keys, or credentials.
- Do not delete user data, rewrite Git history, or force-push.
- Do not deploy to production or modify live services.
- Do not claim tests passed unless they actually ran successfully.
- Prefer small, maintainable changes consistent with existing conventions.
- If blocked, explain the blocker and try a safe alternative.
